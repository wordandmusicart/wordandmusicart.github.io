# Ретроспектива: що власнику доводилося повторювати

Складено 3 жовтня 2026 з ~550 повідомлень власника в сесіях Codex і Claude
(16.09–03.10.2026) та історії PR #1–#95. Кожен пункт закрито правилом в
AGENTS.md / docs/design-system.md і, де можливо, автоматичною перевіркою.
Нова повторна правка → допиши сюди рядок і правило, не лише виправ.
